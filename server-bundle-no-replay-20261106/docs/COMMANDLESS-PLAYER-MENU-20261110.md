# Commandless player menu

Players can right-click empty air with an empty hand to open the Fern menu. The menu is also available to Java and Bedrock players through clickable server-authoritative chat buttons.

The menu provides click actions for:

- Skills
- Class Change Arena
- PvP Arena
- Combiroll craft/cast menu
- Vendor stock and one-click purchases

The Class Change popup remains restricted to `forge_class_arena`. The normal skill panel remains separate. Typed commands remain available as admin and troubleshooting fallbacks, but players do not need to type them for the common flows.
