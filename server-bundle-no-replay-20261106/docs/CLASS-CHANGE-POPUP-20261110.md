# Class Change Arena popup separation

The Class Change popup is allocated only to `forge_class_arena`.

- It opens after the one-time class-arena arrival teleport.
- It reopens when a player crouches and right-clicks empty air inside `forge_class_arena`.
- It shows clickable class choices and the current permanent-class status.
- The normal skill panel remains separate and is opened with the class weapon or `/skills panel`.
