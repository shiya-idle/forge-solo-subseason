# Fern Fabric server — no-replay variant

Use this bundle for the production Minecraft 26.3 Fabric server when no replay or recorder system is wanted.

It contains no Replay Mod, Flashback, FernReplayCapture, or recorder plugin. Do not add those projects to the `mods/` directory.

Install Java 25 or newer, copy this bundle to the VM, verify `SHA256SUMS.txt`, and follow `docs/AWS-VM-PHONE-ONLY-NO-PANEL.md`.
