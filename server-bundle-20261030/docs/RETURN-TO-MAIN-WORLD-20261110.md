# Return to main world panel

When a player is in an arena, the Fern menu includes `RETURN TO MAIN WORLD`.

The panel provides:

- `LAST SEEN PLACE`: the player's last saved position in `minecraft:overworld` before an arena waypoint teleport.
- `WORLD SPAWN`: the shared respawn position of the main overworld.

Both options are clickable and server-authoritative. The typed `/fern return` command remains an administrative fallback.
