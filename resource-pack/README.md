# Forge Solo Subseason Visual Pack

Target: Minecraft Java 26.3, resource pack format 97.1.

This pack contains profile icons, transparent panel/overlay assets, a custom bitmap font, and short placeholder cast/impact/notice sounds. The server sends cast identifiers and announcement text using the `forge_solo:forge` font. The image assets are intentionally subtle and can be replaced by an art pass without changing the server protocol.

Install by uploading `forge-solo-visuals-26.3.zip` to an HTTPS host, then set the server resource-pack URL and SHA-1 in `server.properties`. Keep `require-resource-pack=true` if the UI is required.
