# Fern Bedrock resource pack

This is a Bedrock Edition resource pack for Geyser/Floodgate. Put the `.mcpack` or `.zip` in the Geyser `packs` directory and restart or reload Geyser.

The server sends the live health, mana, and thirst values through the Bedrock action bar. This pack supplies the matching Fern colors, overlays, panel textures, font artwork, and sounds. Java Fabric HUD mixins cannot run inside Bedrock, so the pack does not attempt to install Java code or Java-only HUD logic.

The pack was generated from the Fern Java visual assets. Bedrock and Java resource packs use different schemas; the paths here are deliberately Bedrock paths. Test the pack on the target Bedrock version and device families before making it mandatory.
